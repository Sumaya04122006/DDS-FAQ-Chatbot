# Choose Your Path (decided on Day 1)

On Day 1 you choose one of two flexible paths. Both lead to the same goal: **build, launch and showcase a working AI application.**

## Path 1 – Code-First Path
**Ideal for:** people who want to build with code, AI coding assistants, models and APIs.
**Tools named by the organisers:** Python, Cursor, Claude Code, Codex, OpenAI APIs, Amazon Bedrock and other development frameworks.
**Important:** you do **not** need to write every line manually. AI coding tools can help you plan, generate, debug and improve your application.

### Recommended prerequisites (coding path)
- Basic Python (variables, loops, functions, using libraries)
- Some experience building a small script, notebook project, Gradio app or basic web/API app
- Comfort with Jupyter/Colab and reading technical documentation
If you meet these you will move faster through the checkpoints.

## Path 2 – No-Code / Low-Code & AI App Builder Path
**Ideal for:** people new to coding.
**Tools named by the organisers:** Lovable, Base44, n8n, Flowise, Make and other visual AI app builders.
**You need:** willingness to follow the step-by-step checkpoints, a commitment to watch the tutorials/support recordings, and a builder mindset (test, iterate, improve).
No coding experience is required.

## How to choose (honest advice)
| If you... | Choose |
|---|---|
| Know Python and want full control and a portfolio-grade repo | Code-First |
| Have never coded, or have less than ~10 free hours | No-Code/Low-Code |
| Want an agent that calls custom APIs/tools or uses a vector database | Code-First (or n8n/Flowise low-code) |
| Want a fast MVP and a polished UI quickly | No-Code builder (Lovable/Base44) or Code-First with AI assistant |
| Are stuck choosing | Start with the simplest path that can finish in 8 days. A finished simple app beats an unfinished ambitious one. |

## Judging note
Judging does not automatically favour code over no-code. Criteria are innovation, technical execution, real-world applicability, presentation, and platform leaderboard activity. For no-code projects, "technical execution" is about the quality of your workflow, prompts, tool use and reliability, not hand-written code.

## Can I switch paths?
You pick on Day 1. If you must change later, tell the organisers through the WhatsApp group or connect@decodingdatascience.com and make sure your submissions still reflect one coherent project.
